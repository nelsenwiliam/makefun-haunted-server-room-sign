a program that writes one line — the sign taped to the door of the
haunted server room — to `/output/entry.txt`.

## The sign

> DO NOT REBOOT THE GHOST IN RACK 7. IT LIKES THE UPTIME.

## Run it

```sh
python3 main.py
```

Pure standard library; the program writes `/output/entry.txt` and
nothing else.
